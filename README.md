# chplan_typing

초보자를 위한 타자연습 (자리 · 단어 · 문장, 한국어/English).

- 운영 주소: https://type.chicagoplan.com
- 구성: `index.html` (단일 파일, 외부 라이브러리 없음) + `fonts/` (나눔스퀘어네오 woff, SIL OFL 계열)
- 배포: Cloudflare Pages (Git 연동, 빌드 없음, 출력 폴더 루트)
- 개발 규칙은 `CLAUDE.md` 참고

## 기능 메모
- 사용자 등록(이름만, 최대 8명), 사용자별 기록과 통계. 데이터는 각자 기기의 브라우저에만 저장(서버 없음).
